## Quick setup — if you’ve done this kind of thing before
 or HTTPS | SSH -> https://github.com/springtime3210-beep/Animal-Website.git
 Get started by creating a new file (https://github.com/springtime3210-beep/Animal-Website/new/main)  or uploading an existing file (https://github.com/springtime3210-beep/test2/upload). We recommend every repository include a README, LICENSE, and .gitignore.

## …or create a new repository on the command line
 echo "# test2" >> README.md
 git init
 git add README.md
 git commit -m "first commit"
 git branch -M main
 git remote add origin https://github.com/springtime3210-beep/Animal-Website.git
 git push -u origin main
